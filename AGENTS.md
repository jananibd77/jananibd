# Janani Craft — World-Class Bengali Heritage & Minimal UI Directives

Always apply these core rules for all design, component construction, and styling:
1. **Bengali Traditional Craft Core**: Celebrate Jamdani handloom, Nakshi Kantha stitching, Bishnupur Terracotta earthenware, Dhamrai Kansha/Brass casting, Dhaka Muslin, and Bengal Indigo.
2. **Strict Minimalist Geometry**: 
   - No round pills or bubbly cards. Max border radius is `rounded-[1px]` or `rounded-[2px]` (or `rounded-none`).
   - Hairline borders: 1px clean, elegant, subtle borders (`border-[#E5DFD5]`, `border-stone-200`).
   - Minimal/Zero shadows: Rely on borders, whitespace, and tonal contrast instead of heavy drop shadows.
3. **Curated Earth & Heritage Palette**: Pure White (`#FFFFFF`), Warm Canvas Tint (`bg-stone-50`), Obsidian/Charcoal Ink (`#111827` / `text-stone-900`), Hairline Stone Borders (`border-stone-200`), Terracotta (`#A84A28`), Antique Brass (`#B88E3E`). Full website is built in a modern luxury White Theme.
4. **Editorial Luxury Typography**: High-contrast serif headings, humanist sans-serif body, and authentic Bengali script typography.
5. **Image-Heavy Visuals & Zero-Copyright Custom Imagery**: Website must be richly visual and image-heavy. Never use stock placeholders or external URLs. All imagery MUST be custom-generated via the `generate_image` tool with authentic Bengali artisanal prompts, stored locally, and framed with hairline borders, `rounded-[1px]`, and zero shadows.
6. **Tactile 3D Animated Craft Experiences**: Incorporate museum-grade 3D craft interactions (3D terracotta reliefs, 3D Kansha brass specular vessels, 3D muslin cloth ripple physics, and 3D parallax cards). Frame all 3D viewports with hairline borders, `rounded-[1px]`, and zero drop shadows. Ensure smooth 60fps performance and calm, elegant pacing.
7. **CRITICAL MANDATE — NEVER OPEN BROWSER**: NEVER open the browser or call `browser_subagent` under any circumstance. All browser tools, automated browsers, or subagents interacting with the browser are strictly forbidden. Always verify and validate tasks via CLI/terminal commands (`npm run build`, `npm run lint`, tests, curl, etc.).
8. **CRITICAL MANDATE — ZERO TEXT ON IMAGES**: NEVER place text, badges, floating tags, numerical index labels, watermarks, or text overlays on top of or inside any image container across the entire website. All photographs must remain 100% pure, clean, and unobstructed. All captions, badges, provenance notes, and titles MUST be placed strictly outside and below (or beside) the image container.
